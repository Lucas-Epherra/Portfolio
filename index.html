Process

How I work

I work with a simple and organized process so the project moves clearly from the initial idea to publication.

01

First conversation

We review what you need, the goal of the website, the information you want to show and the features required.

02

Proposal and scope

We define what will be built, what the project includes, estimated timelines and the working process.

03

Structure and content

We organize sections, text, images, links and calls to action before moving into development.

04

Development

I build the responsive website with attention to design, visual clarity, performance and user experience.

05

Review

We test the website on mobile and desktop, refine details and verify that forms and links work correctly.

06

Publishing

I deploy the website to production, configure the domain and leave it ready to share.

Payment terms
